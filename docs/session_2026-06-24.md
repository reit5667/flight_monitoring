## Что нужно сделать дальше

### Запустить бота

1. Создать бота через @BotFather → получить `TELEGRAM_BOT_TOKEN`
2. Получить `TELEGRAM_CHAT_ID` через @userinfobot
3. Заполнить `.env`, запустить Docker, затем:
   ```bash
   source .venv/bin/activate
   python3 -m bot.bot
   ```

### Добавить маршруты в БД

В `routes` сейчас только HAN→KUL, KUL→CMB, CMB→MOW. Для полноценного использования бота нужно добавить нужные маршруты — либо SQL-миграцией `004_seed_routes.sql`, либо командой `/add` в боте (не реализована).
